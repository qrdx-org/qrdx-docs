A token on QRDX is not a contract. It is a registry entry (name, symbol, supply, authorities) and balances held in consensus, so creating one is a single transaction and there is no code to audit. Every native token is also an ERC-20 inside the EVM.

## On trade.qrdx.org

[Launch](https://trade.qrdx.org/launch) creates a token and a market for it at once:

1. **Name, symbol and supply.** Symbols are not unique; the token is identified by its address, which is fixed before the block includes it.
2. **How much you keep.** The rest goes on the **launch curve**.
3. **Launch price and curve.** The curve is a concentrated-liquidity position holding only the new token, from the launch price up to a multiple of it. Buyers swap the quote asset in and walk the price up the range, which behaves like a bonding curve but is an ordinary pool that anyone can trade on, add to or route through.
4. **Pool cost.** Stake QRDX (refunded if the pool is later removed) or burn it (the pool is permanent). The form shows what your network charges: 10,000 to stake or 5,000 to burn before qrdx-node's 2026-10 release, 25 or 10 from it.

The wallet asks you to approve the token, the pool and the curve. They can all land in the same block.

## Authorities

A token has optional authorities. Each can be handed over or renounced; **renouncing is permanent**.

| Authority | Can | If none |
| --- | --- | --- |
| Mint | create new supply, up to the max supply if one is set | the supply is fixed forever |
| Freeze | freeze and thaw accounts' balances of the token | no account can ever be frozen |

A launch on trade.qrdx.org never sets a freeze authority, so nobody can lock a holder's coins. By default it has no mint authority either, so the supply is fixed; you can choose to keep the right to mint (for yourself or another address), and buyers will see that. The explorer shows **Fixed supply**, **Mintable** and **Freezable** on every token page.

## Token standard options

**Token standard options** on the launch form opt the token into the standard's extensions. They are chosen when the token is created and cannot be added later; buyers, wallets and the explorer see each one.

| Option | What it does |
| --- | --- |
| Decimals | how wallets display amounts (0–18; 18 by default) |
| Metadata | a URI and up to 16 fields (website, description, …), editable by you or locked forever |
| Freeze authority | may freeze a holder's balance; optionally every account starts frozen until thawed (permissioned assets) |
| Pausable | you can stop every transfer, mint and burn, and resume them |
| Permanent delegate | may move or burn anyone's balance without permission (a regulated issuer's clawback) |
| Default operators | up to 8 addresses that may move every holder's balance until the holder revokes them (ERC-777) |
| Soulbound | holders can never send it |
| Transfer fee | basis points withheld from every transfer, for you to collect; a new rate applies 100 blocks after it is set |
| Backed by locked classical assets | an advisory flag for trading after the Doomsday Protocol |

A token with a transfer fee, a soulbound token and a default-frozen token cannot be pooled, so those are created as a token only. [Native tokens](/docs/concepts/native-tokens) explains each extension.

## After launch

- The token page on [the explorer](https://explorer.qrdx.org) shows its price, chart, supply, markets and holders' trades.
- As the creator, you can [claim the token](/docs/guides/explorer#claim-a-token) on the explorer and set its image, description and links. QRDX Trade and the wallet show the image.
